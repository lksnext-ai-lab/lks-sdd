# Consultar y explicar en v3

Use status para situar proyecto, petición y tareas. Con catalog localice por tipo y página; history recupera una revisión exacta. Explique quién debe actuar, qué se completó y qué falta. Lea fuentes de la pregunta, sin cargar el histórico completo ni iniciar una adopción por una consulta. En un proyecto v3, use review para explicar qué propuesta concreta está pendiente de validación.

Use `python -B <plugin-root>/scripts/lks_sdd.py v3 ACCION <proyecto> --input <datos.json>`.
Los datos se preparan a partir de documentos y decisiones observados. `--apply`
materializa una operación ya autorizada; no pida permiso por cada registro local.
Para revisar un cambio todavía no autorizado, guarde su paquete con `--output`.
La [referencia de operaciones](../../../docs/V3-OPERATIONS.md) se consulta solo para
los campos concretos que necesite preparar, no se carga íntegra por defecto.

Con recorrido integral activo, use journey/interventions para explicar H1–H7, personas reales, reservas y siguiente acción. No traduzca cada hito a una nueva confirmación ni confunda not-required con una revisión realizada.
