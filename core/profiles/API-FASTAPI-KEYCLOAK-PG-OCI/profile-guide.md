# API-FASTAPI-KEYCLOAK-PG-OCI

Perfil API-only con autorización OIDC, PostgreSQL, migraciones y entrega OCI. Reutiliza el backend certificado del perfil web completo y añade una composición operativa propia sin frontend.

El contrato del proyecto debe definir issuer, audience, scopes/roles, propiedad de datos, migraciones, recuperación, compatibilidad de API, SLO y promoción del artefacto.
