# WEB-ANGULAR-SSR-NODE

Perfil candidato para SSR Angular con runtime Node. Está definido y empaquetado para experimentación controlada, pero no se considera supported hasta superar su gate técnico, composición exacta, eval E2E y revisión.

No debe seleccionarse para evitar el perfil estático; la necesidad de SSR debe justificarse por SEO, rendimiento inicial, personalización o requisitos operativos medibles.
