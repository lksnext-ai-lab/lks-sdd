# Verificar y cerrar en v3

Cargue el contrato literal necesario y contraste el resultado real con cada criterio y prueba. Registre evidence con pruebas cubiertas, resultado real, tipo de observación, sujeto y artefacto recuperable. Un archivo creado no prueba que un test se ejecutó: ejecute o observe el medio acordado. Respete revisión independiente y resultados terminales vigentes de controles obligatorios. Use verify y close después de sus condiciones. Una excepción validada conserva el fallo y las reservas; no declare el control superado. Antes de integrar, contraste candidato y base de confianza, controles conjuntos e interfaces; integrate registra la revisión SDD, sin aprobar el PR ni certificar CI/CD. accept recoge la decisión funcional explícita en el orden del proyecto. Un nuevo cambio invalida únicamente evidencia afectada.

Use `python -B <plugin-root>/scripts/lks_sdd.py v3 ACCION <proyecto> --input <datos.json>`.
Los datos se preparan a partir de documentos y decisiones observados. `--apply`
materializa una operación ya autorizada; no pida permiso por cada registro local.
Para revisar un cambio todavía no autorizado, guarde su paquete con `--output`.
La [referencia de operaciones](../../../docs/V3-OPERATIONS.md) se consulta solo para
los campos concretos que necesite preparar, no se carga íntegra por defecto.
