# Comparativa de métodos de desarrollo

Sitio estático preparado el 7 de octubre de 2026. `dist/` contiene los documentos,
JavaScript, estilos y recursos publicados. Es material comparativo con su fecha
y fuentes propias; sus referencias a versiones no se actualizan automáticamente
con cada release del plugin. Este sitio no forma parte del paquete instalable.

Para consultarlo localmente, desde esta carpeta:

```powershell
node serve.mjs
```

Abre http://127.0.0.1:4173. Los archivos de despliegue personal, capturas temporales
y archivos comprimidos generados se conservan localmente y se excluyen de Git.
