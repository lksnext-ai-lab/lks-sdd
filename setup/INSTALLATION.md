# Preparación del proyecto desde el plugin Copilot

Lea la [guía completa](../core/docs/INSTALLATION.md) y el [itinerario desde cero](../core/docs/LEARNING-GUIDE.md).

Desde esta carpeta ejecute `python install.py copilot RUTA_DEL_PROYECTO` para obtener una vista previa. Solo tras aprobarla, repita con `--apply --authorize HASH_DE_LA_VISTA_PREVIA`. El consumidor debe existir.
