# WEB-ANGULAR-STATIC

Perfil cerrado para SPA Angular sin backend, identidad ni persistencia de servidor. El proyecto consumidor debe decidir alojamiento estático, fallback de rutas, configuración por entorno, telemetría cliente y compatibilidad de navegador.

La certificación combina locks exactos, lint, tipos, tests, build de producción, inspección del bundle, navegador real, accesibilidad y gate de composición. El lock identifica esta composición; no autoriza por sí mismo un despliegue.
