# Isolated verification delivery

The gate provisions disposable synthetic resources. The built artifact and
exact image digests must be recorded. Stop and remove only its named containers
and network with `python verification/gate.py --cleanup`. Never use this command
against a consumer database or production. It is not a deployment authorization.

Migration recovery is a transactional rollback followed by a tested forward fix,
with synthetic records preserved. Shared production deployments require their
own backup, restore rehearsal and release authorization outside this profile.
