# LKS-SDD v0.4.0 — M4 calidad de producto

Release candidate técnica del plugin LKS-SDD para desarrollo Specification-Driven Development (SDD) con Codex.

## Incluye

- Catálogo versionado y auditable FX-01–FX-19.
- Corpus de activación en español con intenciones positivas, negativas y límites operativos.
- Inventario completo y hashes SHA-256 para fixtures exclusivamente sintéticos.
- Runner reproducible con umbrales, reporte JSON, fallos críticos destacados y escritura atómica opcional.
- Comparación de métricas contra la baseline `v0.3.0`.
- Contratos para incorporar observaciones de Codex y revisión documental humana sin almacenar contenido de clientes.

## Validación

La puerta `candidate` exige contrato, perfil, pruebas, evals, fixtures, gate H0 integral en Docker y ausencia de regresiones. La release se publica solo si esa puerta está en `passed`.

## Estado y límites

- Esta versión se publica como prerelease `candidate`.
- Los canales de activación semántica, revisión documental humana y piloto permanecen `not-run` hasta que exista evidencia real saneada.
- El canal `stable` sigue bloqueado; no se interpreta evidencia ausente como éxito.
- Codex continúa siendo el único entorno soportado contractualmente.
- La release no implica política corporativa aprobada, instalación global ni soporte oficial.
