# Estado de licencia y uso

No se ha aprobado todavía una licencia definitiva para LKS-SDD. Este repositorio y los bundles candidate M5 se mantienen para evaluación interna controlada; su presencia o generación no concede por sí sola derechos de redistribución, sublicencia o uso externo.

La selección de una licencia, la política corporativa de uso y la promoción a un marketplace estable requieren una decisión explícita separada. Hasta entonces, el manifiesto omite el campo `license` y la ausencia de licencia debe tratarse como una restricción, no como permiso implícito.
