# Definir, validar y planificar en v3

Prepare unidades de propuesta funcional y técnica o una conjunta, con objetivo, alcance incluido/excluido, comportamiento, solución, impacto, criterios y decisiones pendientes. Use author para registrar Markdown y review para presentarlo: explique claramente que este es el momento de validar y qué permite aceptar. Registre approve solo con la respuesta explícita y su alcance. Después prepare plan y tareas con responsable, rutas, criterios, pruebas, cobertura, dependencias tipadas e integración. authorize-plan permite aprobar el plan y autorizar conjuntamente si esa es la decisión recibida. Un cambio material revalida solo las unidades afectadas. Para gobierno use governance con motivo, configuración previa competente y peticiones afectadas; nunca cambie reglas para fingir una aprobación.

Use `python -B <plugin-root>/scripts/lks_sdd.py v3 ACCION <proyecto> --input <datos.json>`.
Los datos se preparan a partir de documentos y decisiones observados. `--apply`
materializa una operación ya autorizada; no pida permiso por cada registro local.
Para revisar un cambio todavía no autorizado, guarde su paquete con `--output`.
La [referencia de operaciones](../../../docs/V3-OPERATIONS.md) se consulta solo para
los campos concretos que necesite preparar, no se carga íntegra por defecto.
