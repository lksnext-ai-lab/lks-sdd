# LKS-SDD v1.1.0-rc.1

**Fecha:** 2026-09-11. Candidate de desarrollo, no publicada.

## Changelog

Distribución dual Codex desktop/Copilot VS Code Agent, seis adaptadores, núcleo
compartido, lock por proyecto, instalación offline segura y relevo visual hacia Codex.
No hay generación por API desde Copilot ni avisos de relevo en Codex nativo.
Incluye el plugin nativo Agent Plugins 1.0 para el panel Plugins de Copilot, con
preparación explícita del consumidor y migración desde adaptadores sin duplicarlos.
La guía desde cero, el piloto guiado y los procedimientos técnicos se comparten
con la skill de ayuda; no hay dos manuales independientes que puedan divergir.

## Compatibilidad

Schema de proyecto 1.5/método 1.5.0 sin migración. Formato auxiliar de handoff 1.0.
La aceptación conversacional de los hosts sigue pendiente.

## Perfiles y locks

23 perfiles conservados, incluidos los 6 candidate sin promoción. El motor certificado
no se modifica para adaptar herramientas; sus checks exactos siguen siendo obligatorios.

## Validación y evals

Consultar [aceptación dual](../DUAL-HOST-ACCEPTANCE.md). La aprobación de la versión
estable 1.0.0 permanece histórica y no autoriza publicar esta RC.

## Vulnerabilidades conocidas y limitaciones

No se ha ejecutado una auditoría de seguridad específica ni pruebas con tres usuarios.
No hay coordinación distribuida entre escritores simultáneos. SHA-256 detecta corrupción,
no autentica al editor. No se ocultan errores, ausencia de herramientas ni límites de cuenta.

## Actualización

Usar [instalación](../INSTALLATION.md), revisar preview y hash, abrir una conversación nueva.
El runtime se fija por proyecto y las modificaciones locales bloquean sustituciones.

## Migración

No se altera `project.json` ni la procedencia histórica. Los handoffs activos exigen
su versión exacta; cerrar o reconciliar antes de actualizar su runtime.

## Rollback

Retirar únicamente archivos gestionados y reinstalar el paquete anterior verificado.
La versión anterior no entiende relevo dual; no continuar un relevo pendiente con ella.
No borrar ni reescribir imágenes, decisiones, autorizaciones o evidencias consumidoras.

## Soporte

Codex desktop y adaptador Copilot de evaluación. No extensión Codex VS Code ni otros hosts.
Reportar digest, versiones, comando y diagnóstico saneado; no credenciales o chats privados.

## Responsables

Los roles de aprobación y aceptación deben confirmarse para la release. Este documento
no asigna personas ni inventa firma o aceptación humana.
