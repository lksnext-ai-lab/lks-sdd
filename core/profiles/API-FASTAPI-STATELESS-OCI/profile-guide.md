# API-FASTAPI-STATELESS-OCI

Perfil API-only para servicios HTTP sin interfaz, identidad ni persistencia propias. Incluye contrato OpenAPI, pruebas positivas y negativas, health/readiness, análisis estático, tipos y una imagen OCI reproducible.

El proyecto debe decidir versionado y compatibilidad de API, consumidores, límites, seguridad perimetral, observabilidad, SLO y política de promoción y reversión.
