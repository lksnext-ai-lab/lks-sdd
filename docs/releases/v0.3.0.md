# LKS-SDD v0.3.0 — M0–M3

Primera release técnica versionada del plugin LKS-SDD para desarrollo Specification-Driven Development (SDD) con Codex.

## Incluye

- Seis workflows completos: ayuda, definición, adopción de repositorios existentes, readiness, implementación y verificación.
- Contratos documentales trazables, con los Markdown consumidores como fuente canónica y `.lks-sdd/project.json` como índice.
- Perfil H0 `WEB-FASTAPI-REACT-KEYCLOAK-PG`, locks exactos, scaffold reproducible y gates integrados.
- Adopción estática y aditiva, migración `0.9` → `1.0` protegida y vistas cliente derivadas con control de procedencia y contenido sensible.
- Validadores, pruebas unitarias y evals deterministas para M0–M3.

## Compatibilidad

Codex es el único entorno soportado contractualmente. No se declara compatibilidad equivalente con GitHub Copilot, Claude u otros asistentes.

## Validación

La release supera los validadores de las seis skills, el manifiesto del plugin, el contrato M0–M3, el perfil H0, la suite unitaria y las evals documentadas en `docs/VALIDATION.md`. El perfil H0 también cuenta con evidencia de ejecución integral en contenedores.

## Límites

- La baseline normativa y el perfil H0 conservan estado `candidate`.
- La release no equivale a aprobación como política corporativa, instalación global, soporte oficial ni publicación en marketplace.
- La licencia definitiva y las responsabilidades nominales continúan pendientes de decisión.
