# Capacidades y límites de LKS-SDD 0.1.0

## Disponibles

- Explicar el método, ofrecer onboarding y orientar desde el estado de un proyecto sin modificarlo.
- Inicializar de forma aditiva la documentación de una aplicación nueva autorizada.
- Mantener especificaciones profesionales y separar propuestas de decisiones.
- Evaluar readiness de un incremento con bloqueos explicables.
- Validar el índice operativo, metadatos Markdown, identificadores y relaciones mínimas.

## No disponibles todavía

- Descubrir o materializar automáticamente un repositorio existente.
- Generar una aplicación FastAPI/React o seleccionar una pila automáticamente.
- Implementar un incremento o verificar código.
- Publicar, instalar, desplegar, acceder a producción o aprobar excepciones.
- Usar MCP, conectores, hooks, apps o agentes.

La baseline normativa es candidata. Puede orientar un piloto, pero no debe presentarse como política corporativa, certificación ni aprobación formal.
