# LKS-SDD v0.5.0 — M5 piloto preparado

Release candidate técnica del plugin LKS-SDD para desarrollo Specification-Driven Development (SDD) con Codex.

## Incluye

- Marketplace de desarrollo empaquetado con la estructura local estándar de Codex.
- Bundles reproducibles de plugin y marketplace, manifiesto por archivo y checksums SHA-256.
- Plan, onboarding, soporte no sensible y rollback controlado.
- Configuración externa para 3–5 proyectos y 5–8 participantes con aliases.
- Observaciones sin texto libre, almacenamiento fuera del repositorio y resumen agregado sin identificadores.
- Decisión go/no-go vinculada a muestra, rutas, seguridad, permisos, calidad, carga y canales M4.

## Validación

La puerta `candidate` vuelve a ejecutar contrato, perfil, pruebas, evals, fixtures, gate H0 completo y regresión contra `v0.4.0`. Las pruebas M5 verifican bloqueo de la plantilla, privacidad, idempotencia, agregación, no-go de seguridad y reproducibilidad de paquetes.

## Estado y límites

- Esta versión se publica como prerelease `candidate`.
- La infraestructura del piloto está completa; el piloto real no se ha iniciado ni se presentan resultados inventados.
- La plantilla permanece bloqueada hasta asignar proyectos, aliases, roles, canal confidencial, checksum y rollback.
- `stable` requiere observaciones semánticas/humanas, piloto ejecutado y decisión `go`.
- Codex continúa siendo el único entorno soportado contractualmente.
- No existe todavía licencia definitiva, SLA ni aprobación como política corporativa.
