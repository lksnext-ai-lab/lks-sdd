# Contrato de implementación

Use el contexto literal, la autorización vigente, el diff real y las rutas aprobadas de la TASK. Las decisiones tecnológicas críticas deben estar confirmadas en la declaración local del proyecto. `prepare` solo puede crear registros locales autorizados; nunca copia recetas, implementation files, locks u observadores tecnológicos globales.

Conserve cambios ajenos, registre checkpoints y detenga el trabajo si la autorización, el contrato o la evidencia dejan de coincidir.
