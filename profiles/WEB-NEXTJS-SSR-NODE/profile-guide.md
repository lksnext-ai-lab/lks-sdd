# WEB-NEXTJS-SSR-NODE

Perfil cerrado para aplicaciones Next.js con servidor Node persistente, renderizado en servidor e hidratación. No equivale a exportación estática.

La especificación debe cerrar fronteras server/client, caché y revalidación, alojamiento, configuración, secretos, telemetría, escalado y rollback. Los gates prueban build, runtime SSR, hidratación, navegación y accesibilidad sobre la composición exacta.
