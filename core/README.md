Especificaciones por capacidad funcional, definición de tarea y un único plan que
evoluciona durante el trabajo. Seis skills para Codex y GitHub Copilot, autoridad
reutilizable, pruebas proporcionadas, colaboración y migración integral explícita.

- [Modelo, comandos y migración](docs/V5.md)
- [Preparación e instalación](docs/INSTALLATION.md)
- [Validación de esta versión](docs/VALIDATION.md)

La versión 5.0.0 simplifica el modelo y convierte explícitamente los proyectos
anteriores. Publicación, instalación, aceptación de host y piloto se declaran por separado. Los documentos de versiones anteriores
permanecen en el repositorio como historia; el paquete v5 incluye solo su núcleo.
