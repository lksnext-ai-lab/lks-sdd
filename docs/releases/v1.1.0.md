# LKS-SDD v1.1.0

**Fecha:** 2026-09-11. Línea estable dual Codex desktop y GitHub Copilot en VS Code.

## Changelog

Un núcleo, seis skills y dos distribuciones. Copilot incorpora un plugin nativo
Agent Plugins 1.0, instalación desde el panel, runtime fijado por proyecto y setup
offline con vista previa, autorización por hash, retirada y recuperación.
La documentación compartida con la ayuda explica agentes, SDD y colaboración desde
cero. Véase [CHANGELOG](../../CHANGELOG.md).

## Compatibilidad

Schema consumidor 1.5 y método 1.5.0 sin cambio. Codex desktop conserva su flujo
normal de imágenes; Copilot prepara un relevo explícito hacia Codex, con retorno
opcional. No usa una API de imágenes con facturación adicional. La extensión Codex
de VS Code y otros hosts no forman parte del soporte de esta entrega.

## Perfiles y locks

Se conservan 23 perfiles: 17 active con certificaciones exactas y 6 candidate sin
promoción. El runtime se fija por proyecto y se comparte mediante Git, nunca mediante
credenciales o cachés personales. La colaboración es secuencial, no multi-escritor.

## Validación y evals

La aprobación propia `quality/release-approval-v1.1.0.json` registra las pruebas
satisfactorias de Copilot comunicadas por el responsable y su autorización estable.
No se aportó matriz detallada por escenario; esos canales conservan su estado real.
El asset `quality-report.json` acredita gates técnicos del commit exacto. Los bundles
se publican solo tras doble build reproducible y CI correcto. El inventario y
`SHA256SUMS` permiten verificar todos los assets. Véase
[aceptación dual](../DUAL-HOST-ACCEPTANCE.md) para resultados de desarrollo y límites.

## Vulnerabilidades conocidas y limitaciones

No hay auditoría de seguridad específica de esta entrega ni evidencia detallada de
un piloto de tres desarrolladores, todos los recorridos visuales o Rovo/Jira real.
SHA-256 detecta corrupción, no firma al editor. Cada persona necesita su acceso a
GitHub y licencias propias. Las políticas corporativas pueden impedir los plugins.

## Actualización

Sigue la [instalación paso a paso](../INSTALLATION.md). En Copilot usa el catálogo
`https://github.com/lksnext-ai-lab/lks-sdd.git`; ofrece el paquete fijado en
`copilot-v1.1.0`. En Codex usa el marketplace ZIP de esta release.
Actualizar el plugin personal no cambia automáticamente el runtime del proyecto:
ejecuta su setup, revisa la vista previa y versiona los cambios autorizados.

## Migración

Sin migración del contrato consumidor. El setup nativo migra los adaptadores de
proyecto gestionados sin duplicar skills; no sobrescribe personalizaciones. Cierra
o reconcilia los relevos visuales pendientes antes de cambiar el runtime.

## Rollback

Retira únicamente archivos gestionados con el instalador y prepara el paquete
anterior verificado. Conserva documentos, imágenes, decisiones y evidencias del
consumidor. 1.0.0 no entiende relevos duales pendientes; no los continúes con ella.

## Soporte

Codex desktop y plugin Copilot en VS Code. No se establece un SLA corporativo.
Reporta versión, digest, comando y diagnóstico saneado, sin credenciales ni chats.
Publicación estable no equivale a aprobación del método como política de empresa.

## Responsables

La aprobación corresponde al rol responsable del proyecto, registrada sin identidades.
No se asignan responsables de soporte corporativo no confirmados.
